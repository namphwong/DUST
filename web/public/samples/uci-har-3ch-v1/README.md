# UCI HAR demo windows

Six real independent windows, total acceleration including gravity, X/Y/Z in g.
Each CSV has 128 samples; relative display timestamps are 0..2540 ms at 50 Hz.
No windows are concatenated into a reconstructed continuous recording.

Selected by the first official training row per class, without predictions or model selection.
All six belong to subject 1 in the prepared training split. These are interface demos,
not an evaluation set. See index.json for labels, source indices and CSV hashes.

Source: https://archive.ics.uci.edu/dataset/240/human+activity+recognition+using+smartphones

Citation: Davide Anguita, Alessandro Ghio, Luca Oneto, Xavier Parra and Jorge L. Reyes-Ortiz.
A Public Domain Dataset for Human Activity Recognition Using Smartphones. ESANN 2013.
